🧪 Cara Test Feature

1 Buka Admin Create Form

→ Go to Create Form

2 Persiapkan File Excel
  • Gunakan file Excel punya Anda sendiri (.xlsx, .xls, .csv)
  • Pastikan memiliki headers di baris pertama
  • Pastikan ada data di baris-baris berikutnya
3 Upload Excel File

Di section "📊 Insert Tabel dari Excel":

  • Drag & drop file ATAU klik untuk select
  • File akan diproses otomatis
  • Preview popup akan muncul
4 Lihat Preview & Click "Lanjutkan Insert"
  • Preview window menampilkan tabel dengan styling
  • Klik tombol "Lanjutkan Insert"
  • Popup akan close dan tabel akan muncul di editor
5 Verifikasi Tabel di Editor
  • Table harus terlihat di Quill editor dengan styling
  • Headers berwarna biru
  • Rows berganti warna (putih & abu-abu)
  • Borders dan padding terlihat jelas
6 Isi Field yang Diperlukan
  • Judul Pengumuman: required
  • Tanggal Publikasi: required
  • Gambar Pengumuman: optional
7 Submit Form
  • Click tombol "Buat Pengumuman"
  • Form akan submit dengan table data
  • Tunggu redirect ke halaman list
8 Verifikasi di Halaman User
  • Buka /infobase/pengumuman
  • Cari pengumuman yang baru dibuat
  • Klik untuk buka detail
  • Table harus terlihat dengan styling lengkap

Untuk Setiap Step, Check:

  • File Upload: Look for "Processing Excel file" logs
  • CSV Parsing: Check "Data parsed" message dengan row count
  • Table Generation: Verify HTML length di console
  • Editor Insert: Check "Has <table>: true"
  • Form Submit: Verify "Syncing Quill content" and form submit logs

🎯 Jika Masih Ada Masalah

Jika preview popup tidak muncul:
  • Check apakah browser memblok pop-ups
  • Allow pop-ups untuk halaman ini
  • Lihat console untuk error messages
Jika table tidak terlihat di editor:
  • Cek console untuk "Table inserted successfully" message
  • Verifikasi "Has <table>: true" di console
  • Check apakah data ada di localStorage (lihat debug dashboard)
Jika table tidak tersimpan ke database:
  • Buka Network tab di DevTools
  • Cek POST request ke /admin/pengumuman/store
  • Verifikasi request payload include "description" dengan table HTML
  • Check server response untuk error messages
Jika table tidak muncul di halaman user:
  • Check database direktly (tinker atau query)
  • Verifikasi description column punya HTML table
  • Check CSS di pengumuman-detail.blade.php
  • Verifikasi table tidak di-hide oleh CSS line-clamp
