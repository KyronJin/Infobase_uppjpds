📋 Troubleshooting Guide

Problem Solution
Halaman kosong tanpa pesan apapun 1. Buka DevTools (F12)
2. Lihat Console tab - ada error?
3. Lihat Network tab - request /infobase/pengumuman status 200?
4. Coba hard refresh: CTRL+F5
Halaman "Belum ada pengumuman" 1. Check URL - sudah base URL tanpa parameter?
2. Check pagination - apakah di page 2+?
3. Check search - apakah ada ?search= parameter?
4. Database ada pengumuman? Cek: Database Check link
Halaman blank (bukan "Belum ada") 1. DevTools F12 → Console - cari error
2. JavaScript error menyebabkan page tidak render
3. Coba di browser lain
4. Coba incognito mode (bypass cache)
Excel table tidak terlihat 1. Buka detail pengumuman
2. Check source (right-click → View Page Source)
3. Cari <table> - apakah ada?
4. Kalau ada: CSS issue
5. Kalau tidak ada: Database issue
